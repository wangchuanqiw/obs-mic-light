========================================================
OBS 麦克风状态指示灯  (v3 - 稳定版)
========================================================
绿点 = 麦克风开启    红点 = 麦克风关闭
========================================================

【一句话原理】
脚本连接 OBS 的 WebSocket，监听"麦克风_桌面"源的开关状态，
状态一变圆点就跟着变色。跟你怎么操作无关——无论是按住讲话、
按一下开关、还是鼠标点 OBS 静音按钮，只要"麦克风_桌面"静音状态
变了，圆点就变色。

========================================================
【第一次使用：只需 3 步】
========================================================

第1步：OBS 里开启 WebSocket（只需做一次）
  OBS 菜单 -> 工具 -> WebSocket 服务器设置
    ✔ 启用 WebSocket 服务器        端口保持 4455
    设置一个密码（比如 123456）     记住它
  确定后【重启 OBS】让设置生效。

第2步：填密码
  用记事本打开 config.txt，把 password= 后面改成你的密码。
  如果 OBS 里没设密码，就保持空（password=）。
    password=123456
    input_name=麦克风_桌面     <- 一般不用改

第3步：运行
  双击 run.pyw
  （如果双击没反应：右键 -> 打开方式 -> 选 python.exe，
   路径类似 C:\Users\wcq\AppData\Local\Programs\Python\Python313\python.exe）

  屏幕右下角出现圆点 = 成功。
  按你的"麦克风开关键"，圆点应在 绿(开) <-> 红(关) 间切换。

========================================================
【操作说明】
========================================================
  左键按住圆点        -> 拖动到任意位置
  松开左键            -> 固定并记住位置（下次还在那）
  Ctrl + Alt + M      -> 关闭（需 pynput；装法见下方）
  右键圆点 / 托盘右键  -> 关闭（兜底，永远可用）

【安装全局热键支持（可选，仅需一次）】
  如果 Ctrl+Alt+M 没反应，PowerShell 里跑：
    python -m pip install pynput
  装好后重跑 run.pyw 即可。不用也没关系，右键/托盘照样关。

========================================================
【出问题：看 _log.txt】
========================================================
run.pyw 运行后会自动在同目录生成 _log.txt，记录一切：
  连接、回调注册、每次变色、重建……

打开方式：双击"查看日志.bat"，或记事本直接打开 _log.txt。

关键线索：
  "连接成功，监控输入源: 麦克风_桌面"   -> 连上了，源名对
  "事件回调已注册: ..."                -> 事件通道正常
  "检测到事件线程已死亡，触发后台重建"   -> 自动修复中（正常）
  "连接失败: ..."                     -> OBS 没开/没重启/密码错

========================================================
【游戏里看不到圆点】
========================================================
把游戏从"全屏独占"改成"无边框全屏 / Borderless Windowed"。
这是 Windows 图形限制，非脚本问题。几乎所有游戏都支持。

========================================================
【按开关圆点不变色？检查 3 个】
========================================================
1. _log.txt 里有"事件回调已注册"吗？没有 = 连接/密码问题。
2. 你的"开关键"绑在【麦克风_桌面】上吗？
   OBS -> 设置 -> 热键 -> 找"麦克风_桌面" -> "切换静音"
   绑的是你想用的键。（脚本只监听"麦克风_桌面"）
3. 别的程序占用同一热键？换个键试试。
