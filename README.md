# OBS 麦克风状态指示灯

> 一个悬浮在你屏幕上的小圆点，实时显示 OBS 里麦克风的开关状态：
>
> - 🟢 绿色 = 麦克风 **开着**（未静音）
> - 🔴 红色 = 麦克风 **静音**（关闭）

![效果演示](screenshots/demo.gif)

**适合谁**：主播、录音、直播打游戏的人——一边打游戏一边要看麦克风有没有被按静音，又不想切出游戏。

**原理（一句话）**：程序连上 OBS 自带的 WebSocket 服务，监听你指定那个麦克风输入源的"静音状态"变化，状态一变，圆点立刻变色。你按 OBS 静音键、切换声卡、在 OBS 里点静音按钮，圆点都会跟着变。

**难度**：零基础可装，整个过程大约 10 分钟。支持 Windows 和 macOS。

## 第 1 步：安装依赖

需要装两样东西：**Python** 和 **3 个 Python 库**。装一次即可，以后不用再装。

### 1.1 安装 Python（只要装过 3.10 以上版本可跳过）

<details>
<summary>🪟 Windows 用户点这里</summary>

1. 打开 Python 官网下载页：<https://www.python.org/downloads/>
2. 点黄色大按钮 **Download Python 3.13.x** 下载安装包
3. 双击安装包，**最重要的一步**：安装界面最下面有个复选框
   **"Add Python to PATH"（添加到 PATH）**——**一定要勾上！**
4. 点 **Install Now**，等它装完

> ⚠️ 很多小白装完说"pip 不是内部或外部命令"，就是漏勾了上面那个复选框。装错的可以重装一遍。
</details>

<details>
<summary>🍎 macOS 用户点这里</summary>

1. 打开 Python 官网下载页：<https://www.python.org/downloads/>
2. 点黄色大按钮 **Download Python 3.13.x** 下载 macOS 安装包（会自动匹配你的 Apple 芯片）
3. 双击 `.pkg` 文件，一路点"继续 / 安装"，输一次开机密码
4. 装完打开"终端"（按 `Command + 空格`，输入"终端"或 "Terminal"），输入下面命令验证：

   ```bash
   python3 --version
   ```

   能看到 `Python 3.13.x` 就成功了。

> 💡 推荐用官网安装包而不是系统自带 Python，这样权限、命令都最省心。
</details>

### 1.2 安装 3 个 Python 库

先打开"命令行"：

- 🪟 **Windows**：按 `Win + R`，输入 `cmd`，回车
- 🍎 **macOS**：打开"终端"

然后**一条命令**装好所有依赖（复制粘贴进去，按回车）：

```bash
# Windows 用这个：
python -m pip install -r requirements.txt
```

```bash
# macOS 用这个：
python3 -m pip install -r requirements.txt
```

> 需要先把这个项目的 `requirements.txt` 文件下载到电脑上（见[第 4 步](#第-4-步启动程序)）。
> 如果你不想下载 requirements.txt，也可以手动装，效果一样：

```bash
python -m pip install PyQt5 obsws-python pynput        # Windows
python3 -m pip install PyQt5 obsws-python pynput       # macOS
```

### 1.3 验证装好了（可选）

```bash
python -c "import PyQt5, obsws_python, pynput; print('OK')"
```

（macOS 把开头的 `python` 换成 `python3`。）显示 `OK` 就说明依赖全部就绪。

> 📌 macOS 用户注意：`pynput` 是给 Ctrl+Alt+M 退出热键用的。
> 首次使用前需在 **系统设置 → 隐私与安全性 → 辅助功能** 里，把终端（或运行程序的 Python）勾选允许。
> 不授权也不影响使用——只是热键退出不可用，照样能用右键/托盘退出。

## 第 2 步：设置 OBS

在 OBS 里打开 WebSocket 服务（这是程序连上 OBS 的"门"）。**只需要做一次**：

1. 打开 OBS → 顶部菜单 **工具 → WebSocket 服务器设置**
2. 勾选 **启用 WebSocket 服务器**
3. 端口保持默认 **4455**（不用改）
4. 设置一个密码（例如 `123456`），**记住它**，下一步要填
5. 点确定后，**完全退出 OBS 再重新打开**（必须重启，设置才生效）

> 💡 如果你用的 OBS 版本较早、菜单里没有"WebSocket 服务器设置"，请先把 OBS 升级到 **28.0 以上版本**（WebSocket 服务从 28 开始内置）。

## 第 3 步：找到你的麦克风输入端

程序监控的是 OBS 里的**某一个输入源**（比如"麦克风_桌面"）。每台电脑的源名字都不一样，所以要先确定你自己的源名。有 **两种方法，任选一种**：

### 方法 A：自动探测（最省事，推荐）

把 `config.txt` 文件打开（记事本 / 文本编辑），把这一行改成**等号后面留空**：

```
input_name=
```

程序启动时会自动在 OBS 里找第一个麦克风类输入源。启动后打开 `_log.txt`（见[第 4 步](#第-4-步启动程序)），看到这一行就说明找到了：

```
连接成功，监控输入源: 你的麦克风名字
```

### 方法 B：手动指定（最精确）

1. 在 OBS 主界面的**来源**（Sources）面板里，找到你的麦克风来源
2. 看清楚它的**准确名称**（比如 `麦克风_桌面`、`Microphone (USB Audio)`、`Audio Input Capture`）
3. 打开 `config.txt`，把这个名字**原样**填进去：

```
input_name=你的麦克风准确名称
```

> ⚠️ **最容易踩的坑**：这个名字必须和 OBS 里**一字不差**——区分大小写，区分全角/半角，前后不能有空格。
> 不同电脑的名字不同，`麦克风_桌面` 只是开发机上的例子，不要照抄。

#### ⚠️ 编辑 config.txt 时的编码提醒（Windows 用户必看）

本项目所有文件都是 **UTF-8 编码**，程序读取 config.txt 时也固定按 UTF-8 读。

- 🪟 **Windows 记事本**：Win10/11 新版记事本默认就是 UTF-8，直接编辑保存即可；
  如果你是旧版记事本（Win7 或精简系统），保存时请选 **另存为 → 编码 → UTF-8**。
- 如果文件被存成别的编码（比如 ANSI），程序会读不懂，日志里出现 `读取 config.txt 失败`。
- **不要用记事本编辑 `run.pyw` 这类代码文件**（改坏会导致程序无法启动）。改代码请用 VS Code、Notepad++ 等现代编辑器。

### 在同一文件里填好 OBS 密码

`config.txt` 这样填（`password` 填你在[第 2 步](#第-2-步设置-obs)设的密码，`input_name` 按上面任选一种）：

```
password=123456
input_name=你的麦克风准确名称
```

## 第 4 步：启动程序

### 4.1 文件清单

先把项目文件夹下载下来（GitHub 页面上点绿色 **Code → Download ZIP**，解压）。里面有这几个文件：

| 文件 | 作用 |
|---|---|
| `run.pyw` | 主程序 |

### 4.2 运行入口

<details>
<summary>🪟 Windows 用户点这里</summary>

**双击 `run.pyw` 即可**。

如果双击没反应（文件没关联到 Python）：
右键 `run.pyw` → **打开方式** → 选择 Python 3.13（`pythonw.exe`）
或在命令行里手动运行：

```bash
pythonw run.pyw
```
</details>

<details>
<summary>🍎 macOS 用户点这里</summary>

在**终端**里进入项目文件夹，然后运行：

```bash
cd /你的路径/obs-mic-light
python3 run.pyw
```

> 💡 拖拽小技巧：不用一个个打字，在终端输入 `cd `（注意后面有个空格），
> 然后把这个项目的文件夹从访达拖进终端窗口，回车，再输 `python3 run.pyw` 即可。
</details>

### 4.3 启动后检查（30 秒验证）

1. 屏幕右下角出现一个 **红色圆点** → 程序跑起来了
2. 在 OBS 里按一下你的"麦克风静音 / 切换静音"热键 → 圆点变成 **绿色**，再按一下变回红色
3. 左键按住圆点拖动 → 放到你喜欢的位置，松手后位置会被记住，下次启动还在那

### 4.4 怎么退出

| 方式 | 说明 |
|---|---|
| `Ctrl + Alt + M` | 全局热键（需要 pynput，macOS 需辅助功能授权） |
| 右键圆点 | 即点即退 |
| 托盘/菜单栏图标 → Exit | 兜底，永远可用 |

### 4.5 看运行日志（出问题时用）

程序每次运行都会在同一个文件夹里生成 `_log.txt`，记录连接、变色、报错等一切信息。

- 🪟 **Windows**：双击 `查看日志.bat`，会显示最近 40 行
- 🍎 **macOS**：终端里运行 `tail -40 _log.txt`

**几行关键日志的含义**：

| 日志内容 | 意思 |
|---|---|
| `连接成功，监控输入源: xxx` | 连上了 OBS，且源名找对了 ✅ |
| `事件回调已注册: on_input_mute_state_changed` | 事件通道正常 ✅ |
| `检测到事件线程已死亡，触发后台重建` | 事件通道断了，程序在自动修复（正常现象） |
| `连接失败: ...` | 连不上 OBS——见[常见问题](#常见问题排查)第 1 条 |

## 常见问题排查

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 日志显示 `连接失败` | OBS 没开 / OBS 没重启 / 密码不对 | 确认 OBS 已打开；回[第 2 步](#第-2-步设置-obs)重启过；核对 `config.txt` 里的密码 |
| 圆点不变色 | 输入端名字不对，或热键没绑在监控的源上 | 回[第 3 步](#第-3-步找到你的麦克风输入端)重新确认源名；OBS → 设置 → 热键里确认"切换静音"绑的是你填的那个源 |
| 日志出现 `读取 config.txt 失败` | config.txt 被存成了 UTF-8 以外的编码 | 用 UTF-8 编码重新保存 config.txt（见[第 3 步的编码提醒](#在同一文件里填好-obs-密码)） |
| 日志里中文显示成乱码 | 系统代码页/日志工具编码问题 | 不影响程序运行；换用 VS Code 或新版记事本打开 `_log.txt` 查看 |
| 游戏里看不到圆点 | 游戏用了"全屏独占"模式 | 游戏设置里改成"无边框全屏 / 无边框窗口"，这是 Windows 图形限制，不是程序问题 |
| `Ctrl+Alt+M` 退出没反应 | pynput 没装 / macOS 没授权 | 重新执行第 1.2 步安装命令；macOS 检查"辅助功能"授权 |
| 双击 `run.pyw` 没反应 | 文件没关联 Python | 右键 → 打开方式 → 选 Python；或用命令行 `pythonw run.pyw` |
| macOS 上切到别的窗口时圆点消失 | macOS 对悬浮小窗口的显示策略 | 属于系统差异，把 OBS/游戏设为窗口化通常可避免；不影响功能本身 |

## 隐私说明

- `config.txt` 是**明文保存** OBS 密码的。**上传或分享这个文件夹前，请把 `password=` 后面的内容清空**。
- 程序只在本机连接 `localhost:4455` 的 OBS，不上传任何数据。
- 当前版本一次只监控**一个**输入源（`config.txt` 里的 `input_name`）。
